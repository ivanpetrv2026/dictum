# Security policy

## Модель угроз

Dictum — локальное приложение. Аудио никогда не покидает машину: распознавание выполняется whisper.cpp на устройстве. Приложение не собирает телеметрию и не проверяет обновления; серверной части нет.

Что приложение делает:

- захватывает звук с микрофона по умолчанию, пока зажата комбинация (по умолчанию Ctrl+Win);
- держит записанный PCM-буфер в оперативной памяти и освобождает его после распознавания;
- пишет распознанный текст в активное окно через `SendInput`;
- хранит настройки, словарь и архив распознанного в `%APPDATA%\Dictum`.

Чего приложение не делает:

- не устанавливает низкоуровневый хук клавиатуры (`WH_KEYBOARD_LL`) — комбинация определяется опросом `GetAsyncKeyState` каждые 30 мс;
- не читает и не изменяет буфер обмена — вставка идёт через `SendInput` + `KEYEVENTF_UNICODE`;
- не прописывает себя в автозапуск;
- не открывает фоновых сетевых соединений — сеть используется только для загрузки моделей Whisper и опциональной ИИ-очистки (см. «Сетевые соединения»);
- не запрашивает права администратора.

## Почему это важно

Ложные срабатывания антивирусов почти всегда складываются из трёх факторов: неподписанный бинарник, упаковщик, распаковывающий код в память, и поведение, похожее на вредоносное (хук клавиатуры + клипборд + сеть). Этот проект сознательно убирает третий фактор и не использует упаковщики.

Статус подписи один и тот же во всех документах проекта: подпись выполняется в CI (Azure Trusted Signing) и включается автоматически, когда в репозитории настроены секреты `AZURE_*`; пока они не настроены, релизы выходят неподписанными. Проверка подлинности неподписанных сборок — по `SHA256SUMS.txt` и build-аттестациям (см. «Проверка сборки»).

## Сетевые соединения

По умолчанию, до включения ИИ-очистки и до скачивания модели, приложение не делает сетевых запросов. Полный список исходящих соединений:

**1. Загрузка моделей Whisper** (пользователь инициирует из мастера первого запуска или менеджера моделей):

- хост: `huggingface.co`, путь `ggerganov/whisper.cpp/resolve/main/<файл модели>`;
- метод: GET, скачивается один файл модели; в запросе не передаются данные пользователя;
- каждая модель скачивается один раз и сохраняется локально; после этого распознавание полностью офлайн.

**2. ИИ-очистка текста** — опциональна, выключена по умолчанию, включается галочкой в настройках:

- провайдер выбирается в настройках, endpoint по умолчанию для каждого:

| Провайдер | Хост |
|---|---|
| OpenRouter (по умолчанию) | `openrouter.ai` |
| OrcaRouter | `api.orcarouter.ai` |
| TeamRouter | `api.teamorouter.com` |
| Bynara | `router.bynara.id` |
| Свой OpenAI-совместимый endpoint | задаётся пользователем |
| Gemini (напрямую) | `generativelanguage.googleapis.com` |

- отправляется только текст текущей диктовки и системный промпт — без аудио, имени пользователя и идентификаторов устройства;
- API-ключ хранится в Windows Credential Manager (DPAPI) или переменной окружения и не пишется в файлы настроек;
- таймаут настраивается в настройках (по умолчанию 8 с, допустимо 2–30 с, HTTP-клиент ограничен 20 с); при ошибке, отсутствии ключа или выключенной опции вставляется текст, очищенный локальным корректором;
- запрос привязан к явному действию пользователя (отпускание хоткея при включённой опции), фоновых, периодических и скрытых соединений нет.

Инструменты сборки из исходников (`tools/Get-CudaRuntime.ps1`) скачивают CUDA-редист с `developer.download.nvidia.com` — это выполняется на машине разработчика при сборке, не в установленном приложении.

## Проверка сборки

Каждый релиз содержит:

- `SHA256SUMS.txt` — SHA-256 всех артефактов релиза (выкладка сумм восстановлена в CI; в релизах v0.4.0–v0.12.2 файл ошибочно не попадал в архив из-за бага скрипта);
- build-аттестацию происхождения GitHub (`actions/attest-build-provenance`), привязанную к коммиту и запуску workflow — для установщиков (`.exe`); portable-архив аттестацией не сопровождается.

Проверить аттестацию установщика:

```powershell
gh attestation verify Dictum_v0.12.2_x64_full_setup.exe --repo ivanpetrv2026/dictum
```

Проверить контрольные суммы:

```powershell
Get-FileHash Dictum_v0.12.2_x64_full_setup.exe -Algorithm SHA256
# сверить со строкой в SHA256SUMS.txt из релиза
```
