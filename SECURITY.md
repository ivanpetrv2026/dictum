# Security policy

## Модель угроз

Dictum — локальное приложение. Он не отправляет аудио и текст в сеть, не проверяет обновления и не имеет серверной части.

Что приложение делает:

- захватывает звук с микрофона по умолчанию, пока зажата комбинация Ctrl+Win;
- держит записанный PCM-буфер в оперативной памяти и освобождает его после распознавания;
- пишет распознанный текст в активное окно через `SendInput`;
- хранит настройки в `%APPDATA%\Dictum\settings.json` (путь к модели и язык).

Чего приложение не делает:

- не устанавливает низкоуровневый хук клавиатуры (`WH_KEYBOARD_LL`);
- не читает и не изменяет буфер обмена;
- не прописывает себя в автозапуск;
- не открывает сетевых соединений, кроме одного опционального запроса (см. раздел «Сетевые соединения»);
- не запрашивает права администратора.

## Почему это важно

Ложные срабатывания антивирусов почти всегда складываются из трёх факторов: неподписанный бинарник, упаковщик, распаковывающий код в память, и поведение, похожее на вредоносное (хук клавиатуры + клипборд + сеть). Этот проект сознательно убирает третий фактор и не использует PyInstaller. Подпись добавляется в CI.

## Сетевые соединения

По умолчанию приложение не делает ни одного сетевого запроса. Единственное исключение — опциональная ИИ-очистка:

- включается только галочкой в настройках, по умолчанию выключена;
- запрос идёт по HTTPS на единственный хост `api.openrouter.ai` (`/api/v1/chat/completions`);
- отправляется только текст текущей диктовки — без аудио, имени пользователя и идентификаторов устройства;
- таймаут 8 секунд, при ошибке или отсутствии ключа вставляется локально очищенный текст;
- фоновых, периодических и скрытых соединений нет.

Такая схема выбрана сознательно: сетевой вызов привязан к явному действию пользователя (нажатие хоткея при включённой опции), а не выполняется в фоне. Именно фоновый обмен данными в сочетании с перехватом клавиатуры даёт тот профиль, на который реагируют эвристики антивирусов.

## Проверка сборки

Каждый релиз содержит:

- `SHA256SUMS.txt` — контрольные суммы артефактов;
- аттестацию происхождения GitHub (`actions/attest-build-provenance`), привязанную к коммиту и workflow.

Проверить аттестацию:

```powershell
gh attestation verify Dictum_0.1.0_x64_setup.exe --repo <owner>/<repo>
```

## Сообщения об уязвимостях

Открывай приватный issue через GitHub Security Advisories либо пиши на почту, указанную в профиле. Публичное раскрытие — после исправления.
